# Layer 03 — Governance Models

**EATGF Layer:** 03_GOVERNANCE_MODELS
**Governance Scope:** Architecture | Implementation Standard
**Status:** Under Active Development — v1.1-Enhanced (Q3 2026)

---

## Layer Purpose

The Governance Models layer defines the maturity models, capability assessment frameworks, and governance operating models used to evaluate and improve an organisation’s governance posture over time. It provides structured pathways for organisations at different maturity levels — startup, scale-up, and enterprise — to adopt EATGF progressively.

---

## Scope

| Model                           | Description                                                        |
| ------------------------------- | ------------------------------------------------------------------ |
| EATGF Maturity Model            | 5-level governance maturity scale (Initial → Optimising)           |
| Capability Assessment Framework | Structured scoring across all 7 COBIT domains                      |
| Operating Model Templates       | RACI matrices, governance committee structures, reporting cadences |
| Adoption Pathways               | Role-specific adoption guides (Startup / SME / Enterprise)         |

## Control Authority Relationship

This layer **interprets controls** from Layer 02 (Control Architecture) and translates them into maturity criteria and capability indicators. Assessment scores are inputs to Layer 06 (Audit and Assurance).
