# Layer 04 — Policy Layer

**EATGF Layer:** 04_POLICY_LAYER
**Governance Scope:** Policy | Implementation Standard
**Status:** Partially Published — Enterprise Policies v1.0 Available

---

## Layer Purpose

The Policy Layer contains the formal governance instruments of EATGF — charters, mandates, and enterprise policies that translate control requirements into organisationally enforceable obligations. These documents are designed to be adopted directly into an organisation’s formal policy framework with minimal adaptation.
