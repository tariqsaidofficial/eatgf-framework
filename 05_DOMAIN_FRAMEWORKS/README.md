# Layer 05 — Domain Frameworks

**EATGF Layer:** 05_DOMAIN_FRAMEWORKS
**Governance Scope:** Implementation Standard | Architecture
**Status:** Under Active Development — v1.1-Enhanced (Q3 2026)

---

## Layer Purpose

The Domain Frameworks layer provides specialist governance extensions for specific technical domains within the enterprise. Each domain framework is self-contained, cross-standard aligned, and directly traceable to the Master Control Matrix. Domain frameworks are designed to be adopted independently or in combination based on an organisation’s technical footprint.
