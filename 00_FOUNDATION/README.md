## How to Use This Layer

**Governance Leaders:**

- Start with Official Designation
- Reference Master Control Matrix for all control definitions
- Use the Framework Overview to explain the framework to stakeholders

**Control Owners:**

- Find your control in the Master Control Matrix
- Understand criticality, frequency, and evidence requirements
- Reference back to this matrix in all control implementation

**Auditors:**

- Master Control Matrix is your audit scope
- All controls must be traced to this matrix
- No off-matrix control implementations allowed

**External Auditors / Auditing Bodies:**

- Official Designation explains framework identity and authenticity
- Master Control Matrix defines what you're auditing
- Foundation layer proves governance authority
